# Pericarion · experiencia integrada

Copia de la experiencia pública de Francisco Paco Sanchez y Nacho Araoz:
https://pericarion.p-exp-estudiantes.chatgpt.site/

Se conserva la experiencia, con carga voluntaria desde el portfolio y un puente de mensajes del mismo origen para controlar el volumen. Reiniciar vuelve a cargar la simulación conservando la elección de sonido. La tipografía está embebida en style.css. Las bibliotecas Three.js conservan sus avisos de licencia.
